What should the app's page structure look like?

How do users navigate between building and taking quizzes?

A

Home Hub

A home page lists all quizzes and has two entry points: "Create Quiz" and "Take Quiz" (by ID). Builder and Player are separate pages.

Pages
/ → Home (quiz list + actions)
/builder → Create / edit quiz
/quiz/:id → Take quiz
/quiz/:id/results → Results
B

Two-Flow App

No home page. Two dedicated entry points: "Build a Quiz" and "Take a Quiz". Each flow is self-contained.

Pages
/builder → Create quiz (default)
/builder/:id → Edit quiz
/play → Enter quiz ID
/play/:id → Take quiz
/play/:id/results → Results
C

Minimal Single Flow

One page app. Builder and Player sections on the same page, toggled by a tab/mode switch. Results shown inline after submit.

Pages
/ → Builder tab (default)
/ → Player tab (quiz ID input)
Results shown inline after submit
