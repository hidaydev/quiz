Which styling approach?

Pick the UI library / styling setup for the frontend

A

shadcn/ui + Tailwind

Copy-paste component library built on Radix UI primitives. Clean, accessible, easy to customize. Best-in-class DX for React. Recommended.

Pros

  • Polished out of the box
  • Full control over components
  • Accessible by default

Cons

  • Needs Tailwind setup
  • More initial setup
B

Ant Design

Full-featured enterprise component library. Includes form, table, modal, steps — everything needed for this quiz app out of the box.

Pros

  • Rich component set
  • No custom styling needed
  • Good form handling

Cons

  • Opinionated look
  • Heavy bundle size
C

Tailwind CSS only

Utility classes, no component library. Full freedom, minimal dependencies. More manual work for complex UI patterns.

Pros

  • Lightweight
  • No component opinions
  • Fast iteration

Cons

  • Build accessible components from scratch
  • More CSS to write
